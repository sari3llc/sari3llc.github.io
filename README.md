## Publish on GitHub Pages

1. Create a new GitHub repository, for example `sari3-site`.
2. Upload `index.html` and `styles.css` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
5. After GitHub provides the Pages URL, add the custom domain in the same Pages panel.
6. At your domain provider, point the domain DNS records to GitHub Pages. Keep existing MX records if you use email at the domain.

The buttons currently link visitors to the live Sari3 store at `https://hub.sari3.store/`. GitHub Pages can host this static marketing page, but it cannot replace live inventory, customer accounts, carts, payments, or checkout by itself.
